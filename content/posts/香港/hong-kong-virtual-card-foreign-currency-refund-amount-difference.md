# 香港虛擬卡外幣退款與原付款金額不同？匯率、手續費及差額解析

使用虛擬卡購買海外商品或訂閱服務後，如果取消訂單並成功申請退款，可能會發現退回的金額與原本扣款不同。例如，購買時扣除的港幣金額較高，但退款到帳後卻少了一部分；又或者原本以美元付款，退款紀錄卻顯示不同的港幣金額。

這種情況不一定代表商戶少退了款，也可能與外幣兌換匯率、交易結算時間、退款方式或相關手續費有關。

對香港用戶而言，理解海外付款及退款的計算方式，可以幫助你分辨正常的匯率差額與真正需要追查的退款問題。

## 一、為甚麼虛擬卡退款金額與原扣款不同？

### 1. 付款與退款使用不同匯率

如果你使用港幣計價的卡片帳戶支付美元交易，原付款及退款可能在不同日期處理。

假設你購買商品時，1 美元兌換成 7.80 港元；退款處理時，相關匯率變成 7.75 港元。即使商戶退回相同的美元金額，最終顯示的港幣金額仍可能不同。

以上數字只作示例，並非實際匯率。

實際計算方式取決於發卡機構、卡片產品、交易處理流程，以及退款是以原交易貨幣退回，還是經過其他方式結算。

### 2. 外幣交易手續費未必會退回

部分發卡機構或支付產品會對外幣交易收取手續費。

如果原付款時已收取相關費用，而商戶退款只退回商品本身的金額，這筆手續費未必會自動退回。

例如：

- 商品價格：100 美元
- 原交易涉及的外幣手續費：另行收取
- 商戶退款：100 美元

即使商戶已全額退回商品價格，原本收取的手續費仍可能保留，令你感覺實際收到的退款少於最初支出。

不過，並非所有卡片都會收取外幣交易費，也不是所有產品都採用相同的退款政策。應以發卡平台的費用表及交易明細為準。

### 3. 原交易與退款的結算時間不同

付款時，交易可能先以預授權方式記錄，之後才正式結算。退款亦可能需要經過商戶、支付處理商及發卡機構等不同環節。

因此，你在不同時間查看交易紀錄時，可能會看到：

- 原交易仍然顯示 Pending。
- 原交易已完成，但退款尚未入帳。
- 退款已獲商戶批准，但卡片帳戶尚未更新。
- 原交易及退款分別以不同日期顯示。

在確認退款是否完整之前，應先查看交易狀態，避免將尚未完成的結算誤認為退款不足。

### 4. 商戶只退回部分款項

有些退款本身並非全額退款，例如取消部分商品、退回部分課程費用，或根據商戶條款扣除已使用服務的費用。

如果商戶只批准部分退款，即使匯率完全沒有變化，最終退回的金額仍會低於原付款。

建議先核對訂單取消確認、退款通知及商戶列明的退款金額，再與卡片交易紀錄比較。

## 二、如何判斷是匯率差額，還是退款不足？

發現退款金額不一致時，可以按照以下方法核對。

### 第一步：確認原付款貨幣

先查看原交易是以美元、日圓、歐元，還是其他貨幣結算。

要注意，商品頁面顯示的價格不一定等於最終扣款貨幣。有些海外網站會提供港幣計價，但實際使用的付款方式及結算流程可能有所不同。

### 第二步：確認商戶批准的退款金額

查看退款確認電郵或訂單頁面，確認商戶承諾退回多少款項，以及退款是否已完成處理。

如果商戶原本只批准部分退款，就不能直接以商品的完整原價作比較。

### 第三步：核對卡片帳戶中的退款紀錄

在虛擬卡平台查看：

- 原交易金額及貨幣。
- 原交易的實際結算金額。
- 退款金額及貨幣。
- 退款交易日期。
- 相關手續費或其他費用。
- 退款是否仍處於處理中。

如果平台只顯示港幣金額，卻沒有列明原交易貨幣，可以向客服索取更完整的交易資料。

### 第四步：比較實際費用

不要只比較商品原價與退款後的港幣餘額。

更準確的做法，是將原交易的實際支出、商戶退款及相關費用分開核對，了解差額究竟來自匯率、手續費，還是商戶只批准部分退款。

如果仍然無法解釋差額，便應要求發卡平台提供交易計算方式或費用明細。

## 三、用實際例子理解外幣退款差額

假設你使用虛擬卡購買一項海外服務，商品價格為 100 美元。

以下例子只用來說明計算方式，並非任何特定發卡平台的實際收費。


| 項目 | 假設金額 |
| ------- | -------------- |
| 原付款金額 | 100 美元 |
| 原付款換算匯率 | 1 美元 = 7.80 港元 |
| 原付款換算金額 | 780 港元 |
| 退款金額 | 100 美元 |
| 退款換算匯率 | 1 美元 = 7.75 港元 |
| 退款換算金額 | 775 港元 |


在這個例子中，商戶退回了完整的 100 美元，但退款換算後只有 775 港元，與原本的 780 港元相差 5 港元。

這個差額是由示例中的匯率變化造成，並不代表商戶少退了 5 美元。

如果原交易另外收取了外幣交易手續費，而該費用沒有退回，實際的淨支出差額可能更大。

因此，核對退款時，必須先確認商戶退回的外幣金額，再檢查卡片平台如何換算及處理相關費用。

## 四、虛擬卡退款延遲，是否代表金額出錯？

不一定。

商戶批准退款後，款項可能仍需一段時間才會顯示在卡片帳戶。不同商戶、支付處理商及發卡機構的處理時間可能不同。

如果退款尚未到帳，建議先確認以下事項：

1. 商戶是否已正式批准退款，而不是只提交申請。
2. 商戶是否提供退款日期或退款參考編號。
3. 發卡平台是否已收到相關退款紀錄。
4. 原交易是否已完成結算。
5. 平台有沒有公布相關退款的預計處理時間。

如果商戶已確認退款完成，但超過預計處理時間仍未入帳，可以向發卡平台查詢。

提供原交易日期、金額、交易貨幣及退款參考編號，通常有助客服核對紀錄。

## 五、凍結或停用虛擬卡後，外幣退款會怎樣處理？

有些用戶在取消訂閱或完成購物後，會立即凍結或停用相關虛擬卡。

這不代表退款一定無法處理，但實際安排取決於發卡平台的規則。

### 1. 凍結卡片不一定影響退款

凍結卡片通常是限制新的交易，但退款是否可以正常入帳，要視乎產品及平台的處理方式。

如果你預期會收到退款，可以先向發卡平台確認，不要單憑卡片已凍結就認定退款會失敗。

### 2. 停用或更換卡片後應保留交易紀錄

如果原虛擬卡已停用或更換，應保存原交易資料及商戶的退款確認。

部分平台可能會按照原交易紀錄處理退款，但不能假設款項一定會自動轉到新卡。應直接向平台確認退款去向。

### 3. 退款失敗時應先查明原因

如果商戶表示已經退款，但平台查不到紀錄，可以先向商戶索取退款參考編號，再聯絡發卡平台。

避免在未查明原因前，要求商戶重複退款，否則可能增加核對及處理的難度。

## 六、如何減少海外付款及退款時的匯率損失？

### 1. 付款前了解外幣交易費

不同虛擬卡產品的收費方式可能不同。部分可能收取外幣交易費，部分則可能採用不同的匯率計算方式。

付款前應查看發卡平台的費用表，了解外幣交易、退款及相關服務的收費安排。

### 2. 留意商戶提供的貨幣選項

部分海外網站會讓你選擇以港幣或商戶當地貨幣付款。

如果商戶提供港幣結算，可能會使用自己的換算匯率；如果選擇原交易貨幣，則可能由卡組織或發卡機構按適用規則處理兌換。

兩種方式的實際成本不一定相同。付款前可以比較結帳頁面顯示的匯率及可能涉及的費用，不要只因為看到港幣價格便假設成本最低。

### 3. 保存原交易及退款證明

對於金額較大的海外購物或訂閱服務，建議保存訂單確認、原交易紀錄及退款通知。

當退款金額與預期不同時，這些資料可以幫助你快速核對差額，亦方便向商戶或發卡平台提出查詢。

### 4. 不要忽略小額手續費

小額交易的費用可能看起來不明顯，但如果經常進行海外購物、訂閱軟件或購買數碼服務，累積的手續費亦可能增加整體支出。

定期檢查交易明細，有助了解實際付款成本。

## 七、常見問題 FAQ

### Q1：虛擬卡退款比原付款少，是不是商戶少退錢？

不一定。可能涉及匯率差額、未退回的手續費，亦可能是商戶只批准部分退款。

應先比較商戶確認的退款貨幣及金額，再核對發卡平台的結算紀錄。

### Q2：外幣退款一定會使用原付款時的匯率嗎？

不一定。實際處理方式取決於發卡機構、卡片產品及交易結算規則。有些退款可能以原交易貨幣退回，再按適用方式換算。

應向發卡平台確認相關產品的退款及匯率計算政策。

### Q3：商戶已退回全額美元，為甚麼港幣金額仍然不同？

如果原付款與退款使用不同的匯率，換算後的港幣金額就可能出現差異。另外，原交易收取的部分費用也未必會自動退回。

### Q4：退款顯示成功，但虛擬卡餘額沒有增加，應該點算？

先確認退款是否已完成入帳，而不是只顯示商戶已批准。若超過平台提供的預計處理時間，應提供交易及退款參考資料，向發卡平台查詢。

### Q5：虛擬卡停用後，外幣退款還能退回嗎？

有可能，但不能一概而論。應向發卡平台確認停用卡片後的退款處理方式，以及款項會否退回原交易帳戶。

### Q6：如果退款差額很小，還需要查詢嗎？

如果差額可以由匯率或已列明的手續費解釋，未必需要進一步申訴。但如果金額無法核對、商戶只退回部分款項而沒有合理說明，或出現重複扣款，就應要求商戶或發卡平台進一步調查。

## 結語

香港用戶使用虛擬卡支付海外商品或訂閱服務後，退款金額與原扣款不同，可能是匯率變化、手續費或商戶退款安排所致，未必代表退款出現錯誤。

處理時，應先核對原交易貨幣、商戶批准的退款金額及卡片平台的實際入帳紀錄，再判斷差額是否合理。如果仍然無法解釋，便應保留交易證明，向商戶或發卡平台查詢。

付款前了解外幣收費、付款時留意結算貨幣，以及保存完整的交易紀錄，都有助減少退款爭議，令海外付款更容易管理。
