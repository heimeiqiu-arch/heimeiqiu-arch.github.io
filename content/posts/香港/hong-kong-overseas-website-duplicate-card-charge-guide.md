# 海外網站重複扣款怎麼辦？香港用戶核對信用卡交易指南

在海外網站購物、購買網上服務或訂閱軟件時，有時會發現信用卡交易紀錄中出現兩筆相同或相近金額的款項。這種情況容易令人擔心：究竟是商戶真的扣款兩次，還是其中一筆只是暫時授權？

先不要急著重複付款，也不必立即認定商戶出錯。**處理重複扣款的第一步，是分清楚待處理授權、正式入帳交易，以及真正的重複收費。**

## 一、為甚麼信用卡會出現兩筆相同金額？

### 1. 一筆是預授權，另一筆是正式扣款

部分商戶會先進行授權，再根據實際訂單完成正式結算。交易紀錄可能在一段時間內同時顯示兩筆相關項目，但不一定代表兩筆都已正式收取。

應查看交易狀態、日期及商戶提供的收據，而不是只比較金額。

### 2. 網站付款時重複提交訂單

網頁載入緩慢、付款畫面沒有即時回應，或使用者在等待期間再次按下付款按鈕，都可能令商戶收到重複訂單請求。

不過，重複按下按鈕不一定會造成重複扣款，因為部分商戶設有防重複交易機制。最終仍應以訂單紀錄及交易狀態為準。

### 3. 同一服務存在兩筆訂單

如果你重新整理訂單、再次購買，或不小心建立兩個相同的訂閱方案，便可能真的產生兩筆獨立交易。

這種情況下，兩筆款項即使金額相同，也可能分別對應不同的訂單編號。

### 4. 商戶名稱不同，但其實是同一筆交易

部分海外商戶會透過支付服務商或母公司名稱顯示交易。你可能在卡片紀錄中看到不熟悉的商戶名稱，以為是另一筆扣款。

可以先比對交易日期、金額、訂單收據及商戶說明，再判斷是否屬於同一筆消費。

## 二、怎樣判斷是否真的被扣款兩次？

建議先整理以下資料：

| 核對項目 | 應該留意甚麼 |
|---|---|
| 交易狀態 | 是待處理、授權中，還是正式入帳？ |
| 交易日期 | 兩筆交易是否在同一時間出現？ |
| 交易金額 | 金額是否完全相同？ |
| 訂單編號 | 是否對應同一個訂單？ |
| 商戶收據 | 商戶是否發出兩張收據？ |
| 服務紀錄 | 是否真的建立了兩次訂單或兩個訂閱？ |

如果其中一筆仍然顯示 Pending 或類似待處理狀態，可以先向商戶確認是否屬於授權交易。授權何時釋放，則可能取決於商戶、收單機構及發卡平台的處理流程。

如果兩筆交易均已正式入帳，而且商戶確認只有一筆有效訂單，就應要求商戶調查多出的交易。

## 三、發現重複扣款後，應該怎樣處理？

### 第一步：保存交易證據

截取相關交易紀錄，並保留訂單確認信、付款收據、訂單編號及商戶往來訊息。

分享資料時，應遮蓋完整卡號、安全碼及其他不必要的個人資料。

### 第二步：查看商戶帳戶

登入海外網站的官方帳戶，檢查訂單列表、訂閱管理頁面及付款歷史，確認是否存在重複訂單。

如果只有一張有效訂單，但信用卡出現兩筆正式扣款，應向商戶提供兩筆交易的日期、金額及參考編號，請對方核實。

### 第三步：聯絡商戶要求調查

清楚說明你只進行了一次購買，但交易紀錄出現兩筆相關款項。請商戶確認是否重複收費，以及是否會取消其中一筆交易或安排退款。

建議使用商戶官方網站的客服渠道，並保留對話紀錄。

### 第四步：必要時聯絡發卡平台

如果商戶沒有回覆、拒絕處理，或交易並非由你本人授權，可以向發卡平台查詢後續處理方式。

如需提出交易爭議，應提供真實、完整的資料，並按照發卡平台的程序提交證據。不要在尚未確認交易狀態前，同時把所有待處理授權都當成已完成扣款。

## 四、如果其中一筆交易仍然待處理，應該立即申請退款嗎？

不一定。

待處理授權與正式入帳交易的處理方式可能不同。有些授權會在商戶取消交易後釋放，有些則需要等待相關支付系統更新。

你可以先確認：

- 商戶是否已取消其中一筆訂單。
- 該筆交易是否仍然待處理。
- 商戶是否已提交取消授權或退款操作。
- 發卡平台是否能提供交易狀態及後續處理指引。

如果交易已正式入帳，商戶確認需要退回款項，便應按照商戶的退款流程跟進。退款入帳時間可能因商戶及發卡平台而異。

## 五、怎樣減少海外付款時的重複交易？

- 付款後先等待系統回應，不要因頁面短暫沒有反應便立即再次付款。
- 如果畫面出錯，先查看訂單歷史及交易紀錄。
- 保存訂單編號和付款確認資訊。
- 訂閱服務應定期檢查方案數量及續訂狀態。
- 對於不熟悉的交易名稱，先核對收據和商戶資料再作判斷。

## 六、甚麼情況下應特別留意？

如果交易不是你本人發起、商戶名稱完全陌生，或出現多筆無法解釋的扣款，就不應只把它當成一般重複付款。

建議盡快透過發卡平台的官方渠道查詢，按需要暫停卡片或採取其他安全措施。切勿向自稱客服的人士提供密碼、完整卡片安全資料或一次性驗證碼。

**總結：** 海外網站出現兩筆相同金額，不一定代表真正重複扣款。先核對交易狀態、訂單編號及收據，再聯絡商戶或發卡平台，能更有效地分辨授權與正式收費，避免不必要的重複付款或錯誤申訴。
