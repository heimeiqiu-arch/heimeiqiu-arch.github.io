# Microsoft Advertising 付款失败怎么办？先区分预付和后付账户

Microsoft Advertising（常称 Bing Ads）出现付款错误或广告无法投放时，先确认账户使用的是预付余额、后付阈值扣款还是月结发票。不同付款模式对应的处理步骤不同：预付账户可能需要先充值并确认资金入账；后付账户需要核对主付款方式和账单状态；月结客户则应按账单协议处理。不要把所有情况都当成“银行卡被拒”。

Microsoft 官方广告帮助文档说明，只有具备完整权限的 Super Admin（超级管理员）才能添加、编辑或删除付款方式。即使卡片已经添加，也要确认它是否已被设为该账户的 primary（主付款方式），并确认当前用户是不是 bill-to party（账单付款方）。

## 一、检查用户权限和账单责任方

先登录 Microsoft Advertising，选择目标广告账户，再进入左侧 Billing（账单）下的 Payment methods（付款方式）。核对你是否拥有超级管理员权限，以及付款方式是否已经关联到正确账户。广告活动管理员可能可以编辑广告，却没有权限添加或设置付款卡。

如果卡片已显示，但页面没有标记为 primary，查看是否有 Set as primary（设为主付款方式）选项。微软官方文档提示，只有账单付款方才能指定主付款方式；如果你不是 bill-to party，需要由该付款责任方设置。公司代理商或共享客户账户可能由客户企业而不是代运营人员负责付款，应先确认合同和账户的付款归属。

## 二、确认当前使用的是预付、后付还是月结

预付账户需要先为余额充值。Microsoft Advertising 官方说明，完成充值后，金额应反映在账单摘要页的 Total balance（总余额）中。信用卡审批通常会很快完成，但在卡片处理系统延迟时可能需要最多 24 小时。如果超过 24 小时仍有账户错误，官方建议联系支持。

后付阈值账户则会在达到结算条件时向主付款方式扣款。若扣款被拒，账户可能进入 hold（暂停）状态，广告可能无法继续投放。查看账单摘要和账户错误状态，确认是否存在被拒的费用或未结金额。不要通过重复充值来代替处理后付账户的欠款。

月结发票账户的账单方式和银行卡预付流程不同。根据公司合同查看发票、到期日和账单联系人；若没有信用卡管理入口，联系企业账单负责人或 Microsoft Advertising 支持确认付款方式和账户状态。

## 三、添加付款方式并正确设置主卡

进入 Billing 下的 Payment methods，添加符合账户条件的付款方式，并按页面显示完成验证。保存后再次回到付款方式列表，确认卡片关联到账户且标记为 primary。若付款方式加在其他广告账户或账单实体下，它不会自动替当前账户支付费用。

微软官方帮助文档指出，卡片信息必须与发卡行记录准确匹配。持卡人姓名应按卡面信息填写；公司卡需要根据页面姓名字段说明拆分公司名称；地址过长时使用 Address 1 与 Address 2，而不是随意缩写。卡号不能通过编辑方式修改，若输入错误需要重新添加正确卡片；可编辑的资料可能包括账单地址和有效期。

输入卡号时不要带空格或标点。保存后若仍失败，检查银行是否拒绝线上或广告类商户交易，并确认当前地区、账户币种和银行卡发行地符合微软的支付要求。不同地区的支付方式限制可能不同，按账户帮助页面为准。

## 四、银行卡验证和预付卡限制

Microsoft Advertising 官方文档说明，需要付款时输入 PIN 或安全验证的信用卡可能无法用于账户支付。若银行或卡片要求特定的 PIN 验证，而广告账单流程不支持该方式，应联系发卡行了解是否有另一种适用卡片或付款方式，不要反复尝试相同卡片。

预付卡的使用也受条件限制。微软文档指出，预付卡只可用于部分地区的预付账户；印度账户或用于结清后付阈值费用时需使用其他卡片或付款形式。巴西和印度还可能有币种匹配要求，即卡片国家、账单地址与广告账户币种需符合官方规则。不要通过改变虚假账单地址绕过地区要求，这会导致账户资料不一致。

## 五、付款失败后检查账户状态

进入账户错误或账单页面查看具体状态。微软广告帮助资料对账户状态有不同说明：例如后付阈值账单因主付款方式扣款被拒，账户可能处于 hold；未添加付款方式的账户可能显示 pending。处理前应确认页面当前说明的是付款欠款、缺少付款方式还是其他审核问题。

如果出现欠款，先确定应支付金额和付款模式，再由有权限的人更新主卡或按照账单方式付款。支付方式更新后，查看交易是否成功、余额是否变化以及账户错误是否清除。付款成功也不代表广告必然立刻恢复，Campaign Manager 还可能显示广告审核、预算、排期或政策状态；分别查看账单错误和广告活动状态。

## 六、待处理授权与充值未更新

银行账户中出现待处理授权，不等于充值或广告账单已经完成。查看 Microsoft Advertising 的交易记录与总余额，再对照银行交易状态。若充值已获银行授权但总余额未更新，微软官方资料表示某些卡片处理可能有系统延迟；不要在状态未明时连续充值。

记录交易日期、币种、金额、卡片末四位和页面错误提示。若银行显示已入账而广告账户仍没有余额或仍处于暂停状态，联系 Microsoft Advertising 支持并提供交易参考编号。提交截图时遮挡完整卡号、安全码和其他无关交易。

## 七、联系支持前准备的信息

准备广告客户编号、目标账户 ID、付款模式、付款方式状态、充值或发票编号、交易时间和银行端状态。若你不是超级管理员或账单付款方，先让对应人员核对权限和付款记录。公司客户可联系采购、财务或代理商账单负责人确认发票和账户主体。

只从 Microsoft Advertising 官方帮助中心或账户后台进入支持流程。不要把管理员登录密码、银行验证码或完整卡片信息交给他人。保留支持案件编号，以便在账户状态未恢复时继续核对。

## 常见问题

### 卡片添加成功但广告账户仍提示没有付款方式，为什么？

可能卡片没有设为当前广告账户的主付款方式，或付款责任方不是当前登录用户。进入 Payment methods 检查 primary 标记，并确认你是 bill-to party 或由该方设置。

### 预付账户充值后，余额多久更新？

微软官方资料说卡片审批通常很快，但处理延迟时可能需要最多 24 小时。确认账户没有其他错误；超过 24 小时仍未更新时联系 Microsoft Advertising 支持。

### 普通广告管理员能修改信用卡吗？

微软官方文档要求完整权限的 Super Admin 才能添加、编辑或删除付款方式。请联系账户管理员或账单付款方处理。

### 付款成功后广告会马上恢复吗？

不一定。分别查看账单状态、账户错误和广告活动投放状态。若账单已处理但账户仍显示 hold，通过官方支持核实是否有其他限制。

## 排查清单

1. 确认广告账户和账单责任方。
2. 检查付款模式是预付、后付阈值还是月结。
3. 核实有权限的超级管理员已添加卡片并设为主付款方式。
4. 按发卡行记录核对姓名、地址、卡片有效期和卡号格式。
5. 依据地区规则检查卡片类型、账户币种及预付卡资格。
6. 待处理交易未明时不要重复付款；保存交易参考信息。
7. 付款后重新检查账户错误、账单余额和广告状态。

如果企业需要为国际广告支出或软件服务付款，可以了解 CBPayments 产品说明，核对地区覆盖、适用场景与服务条款后再评估。Microsoft Advertising 接受的付款方式取决于账户地区、账单模式和资格，不保证第三方支付产品适用于所有广告账户。
