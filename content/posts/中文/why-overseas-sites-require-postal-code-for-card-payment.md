# 海外网站为什么要求填写邮政编码？CBPayments AVS 地址验证说明

在海外网站付款时，用户经常会看到 Postal Code、ZIP Code 或 Billing ZIP 等字段。有些网站甚至只要求填写邮政编码，没有要求完整地址。对于不熟悉海外支付表单的用户来说，很容易不知道应该填写什么。

实际上，邮政编码不只是物流信息。在部分银行卡线上交易中，它还可能参与账单地址验证。

## 一、为什么付款页面需要邮政编码？

邮政编码可以帮助商户识别账单地址所在的区域。部分支付系统会使用 AVS，也就是 Address Verification Service，对用户提交的账单地址信息进行核对。

在支持 AVS 的交易中，系统可能比较用户填写的地址或邮政编码与发卡机构登记信息是否匹配。不同国家和地区的支持程度并不相同，商户也不一定对所有交易采用相同的验证规则。

## 二、邮政编码填写错误会导致付款失败吗？

有可能，但并不是所有网站都会严格核对邮编。如果商户启用了地址验证，邮政编码不匹配可能导致验证结果异常，进而影响交易授权。

此外，有些网站还会根据账单国家、地区和其他地址信息进行综合判断。因此，邮编不能简单地当作一个无关紧要的字段。

## 三、虚拟卡用户应该填写哪个邮政编码？

应先确认卡片对应的账单地址信息。如果发卡平台提供了账单地址或邮政编码，应优先按照平台提供的信息填写。如果平台没有提供相关资料，不建议随意使用网络上找到的地址或邮编。

不同卡片产品可能采用不同的账单资料规则，不能把某一张卡片的邮编直接用于所有其他卡片。

## 四、ZIP Code 和 Postal Code 有什么区别？

两者都与邮政编码有关，但常见使用地区和格式不同。ZIP Code 通常用于美国地址；Postal Code 则是更广泛的表达方式。不同国家的邮政编码格式也可能不同，有些由数字组成，有些则包含字母和数字。

如果海外网站只接受数字，而用户所在地区的邮编包含字母，可以先查看网站是否支持当前账单国家和地区，不要随意删除或替换字符。

## 五、AVS 验证失败怎么办？

确认账单国家或地区是否选择正确；检查邮政编码是否与发卡平台提供的资料一致；确认网站要求的是账单地址而不是收货地址；检查地址字段是否有字符格式限制。如果资料正确但仍然失败，联系发卡服务商确认该卡片是否支持相关地址验证。

## 六、收货地址和账单地址不能随意混用

收货地址用于商品配送；账单地址则是与付款账户相关联的信息。两者可能相同，也可能不同。如果网站将两个地址分开填写，应根据字段名称分别提供资料，不要直接把收货地址复制到账单地址栏。
