Review source word counts, translation memory discounts, minimum charges, and revision terms before paying a localisation provider.

Language and document-processing services may charge by word, character, audio minute, page, or API request. Before choosing a plan, confirm the exact unit and how additional usage is billed.

## Check the pricing model

Read the provider's official pricing and usage documentation. Confirm included quotas, language or file-type differences, minimum charges, batch processing rules, billing currency, and renewal conditions. Save the plan details for later comparison.

## Monitor usage

1. Assign an owner to the service.
2. Review the provider's usage report regularly.
3. Check file sizes, word counts, page totals, or request volume.
4. Set alerts where available.
5. Compare invoices with actual usage and saved pricing terms.

## Investigate a higher bill

Look for longer files, additional languages, more pages, premium features, or retries. Ask the provider for an itemised explanation if the invoice differs from your estimate. Verify transaction status before repeating a payment.

Protect API keys and payment credentials. Virtual card acceptance varies by provider, so check supported methods before subscribing.

## FAQ

### Why does processing cost vary between files?
Pricing may depend on page count, word count, language pair, audio duration, file size, or selected processing features.

### What records are useful?
Keep invoices, usage logs, plan details, transaction references, and notes about unusual processing jobs.

## Final takeaway

Understand the billing unit, monitor usage, and reconcile invoices against provider reports.
