# バーチャルカードのCVV・CVCとは？入力時の注意点

オンライン決済でバーチャルカードを使うと、カード番号、有効期限に加えて「CVV」や「CVC」と呼ばれるセキュリティコードの入力を求められることがあります。どの番号を入力すればよいのか分からなかったり、カード番号の一部と混同したりする人もいるでしょう。

CVVやCVCは、オンライン決済時などでカード情報を確認するために使われるセキュリティコードです。カード番号や暗証番号とは役割が異なり、他人に知られないように管理することが大切です。

この記事では、CVVとCVCの基本、バーチャルカードでの確認方法、入力エラーが起きたときの対処法を解説します。

## CVV・CVCとは？

CVVは「Card Verification Value」、CVCは「Card Verification Code」の略称です。どちらもカードのセキュリティコードを指す用語として使われます。

ブランドやカード商品によって名称や表示方法は異なります。一般的には、オンライン決済時にカード番号や有効期限とあわせて入力を求められることがあります。

セキュリティコードは、カード番号そのものでも、銀行口座の暗証番号でもありません。決済画面で「CVV」「CVC」「Security Code」などと表示されている場合は、カードサービスが指定するセキュリティコードを確認してください。

## バーチャルカードのセキュリティコードはどこで確認する？

バーチャルカードには物理的なカードがないため、カード情報をアプリやウェブサイトで確認する形式が一般的です。ただし、具体的な表示方法はサービスによって異なります。

確認する際は、次の手順を参考にしてください。

1. カードサービスの公式アプリまたは公式ウェブサイトにログインする。
2. 対象のカードを選択する。
3. カード情報の表示機能がある場合は、画面の案内に従う。
4. CVVやCVCに該当するセキュリティコードを確認する。
5. 決済画面の入力欄と照らし合わせて入力する。

サービスによっては、セキュリティ上の理由からカード情報を表示する前に追加認証が必要な場合があります。また、カード情報の表示や管理に関する機能は、利用するサービスの仕様に従ってください。

## CVV・CVCを入力するときの注意点

### 1. カード番号と混同しない

カード番号はカードを識別するための番号で、CVVやCVCは別のセキュリティコードです。決済画面の入力欄をよく確認し、それぞれ正しい情報を入力しましょう。

### 2. 桁数や入力形式を確認する

セキュリティコードの桁数や表示方法は、カードブランドや商品によって異なる場合があります。入力欄に指定された形式に従い、推測で数字を入力しないようにしてください。

### 3. 安全な公式画面で入力する

カード情報を入力するときは、正規の加盟店サイトや信頼できる決済画面であることを確認しましょう。メールやメッセージで送られてきた不審なリンクからカード情報を入力することは避けてください。

### 4. コードを他人に共有しない

CVVやCVCは機密性の高いカード情報です。第三者に送信したり、公開された場所に保存したりしないようにしましょう。サポートへ問い合わせる場合も、必要以上のカード情報を送らないことが大切です。

## CVV・CVCを入力しても決済できない原因

セキュリティコードを正しく入力したつもりでも、決済に失敗する場合があります。考えられる原因は次のとおりです。

### 入力したコードが正しくない

数字の入力間違いや、別のカードのコードを入力したことが原因かもしれません。公式のカード管理画面で対象のカード情報を確認し、入力欄をもう一度チェックしましょう。

### 有効期限やカード番号に誤りがある

セキュリティコードが正しくても、カード番号や有効期限に誤りがあれば決済が失敗することがあります。入力欄を一つずつ確認してください。

### 加盟店がカードを受け付けていない

加盟店によっては、利用できるカードブランド、発行地域、カード商品などに制限がある場合があります。カード情報が正しくても、加盟店側の条件によって決済が拒否されることがあります。

### 別の認証や承認に失敗している

決済では、セキュリティコードの確認以外にも、本人認証やカード発行元による承認などの処理が行われることがあります。エラーメッセージやカード明細を確認し、CVVの入力だけが原因だと決めつけないようにしましょう。

## 入力エラーが続く場合の対処法

決済が失敗した場合は、次の点を確認してください。

- 正しいカードを選択しているか
- カード番号、有効期限、CVVまたはCVCが正しいか
- 加盟店がそのカードを受け付けているか
- カードが利用可能な状態か
- カード明細に保留中の取引が作られていないか

何度も入力を繰り返す前に、エラーメッセージを確認しましょう。解決しない場合は、加盟店またはカードサービスの公式サポートへ問い合わせてください。

## よくある質問

### CVVとCVCは同じものですか？

どちらもカードのセキュリティコードを指す用語として使われますが、名称や細かな仕様はカードブランドや商品によって異なります。決済画面で指定された項目に従って入力してください。

### バーチャルカードにもCVVやCVCがありますか？

カード商品によって異なります。オンライン決済用のバーチャルカードでは、カード情報の一部としてセキュリティコードが提供される場合があります。利用するサービスの公式案内を確認しましょう。

### サポートにCVVを伝えてもよいですか？

セキュリティコードは機密情報として扱い、安易に共有しないでください。問い合わせ時は、サポートの公式窓口を利用し、求められた情報が本当に必要か慎重に確認しましょう。

## まとめ

CVVやCVCは、オンラインカード決済で使われるセキュリティコードです。カード番号や暗証番号とは異なるため、入力欄を確認し、正しい情報を入力する必要があります。

カード情報は公式の管理画面で確認し、安全な決済画面だけで使用しましょう。入力エラーが続く場合は、ほかのカード情報や加盟店の利用条件、認証状態もあわせて確認してください。
