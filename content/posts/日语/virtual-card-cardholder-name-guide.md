# バーチャルカードのカード名義とは？海外サイトで入力するときの確認方法

バーチャルカードを海外サイトやオンラインショップで利用するとき、カード番号や有効期限、CVVだけでなく、**Cardholder Name（カード名義）**の入力を求められることがあります。

「バーチャルカードには実物のカードがないのに、カード名義は何を入力すればいい？」

「自分の名前を入力すればいい？」

と迷う人も少なくありません。

カード名義の入力方法は、利用するカードサービスや決済サイトによって異なる場合があります。そのため、自己判断で適当な名前を入力するのではなく、カード情報として表示されている名義を確認することが重要です。

この記事では、バーチャルカードのカード名義とは何か、海外サイトでどのように入力するのか、名義が原因で決済できない場合の確認ポイントについて解説します。

## バーチャルカードのカード名義とは？

カード名義とは、そのカードに関連付けられている利用者名や登録名などを指します。

海外の決済画面では、一般的に、

**Cardholder Name**

**Name on Card**

などの項目として表示されます。

物理カードではカード表面に名前が印字されていることがありますが、バーチャルカードではアプリやWeb管理画面などに表示されるケースがあります。

表示方法はカードサービスによって異なります。

## バーチャルカードに実物の名前が書かれていない場合は？

バーチャルカードには実物のカードがないため、カード名義を画面上で確認する必要があります。

カード情報の画面に、

- Cardholder Name
- Name
- Name on Card
- Card Name

などの項目が表示されている場合があります。

海外サイトでCardholder Nameの入力を求められた場合は、基本的にカードサービス側で案内されている情報を確認して入力するのが安全です。

## 自分の名前を入力すればいい？

必ず自分の名前を入力すればよいとは限りません。

カードサービスによっては、登録した利用者名がカード名義として使用される場合があります。

一方で、カードごとに異なる名義情報が設定されるケースも考えられます。

そのため、

**「自分の名前を入れる」ではなく、「カード情報に表示されている名義を確認する」**

という考え方が重要です。

## 海外サイトでは英字入力が一般的

海外のオンラインショップでは、Cardholder Nameを英字で入力することが一般的です。

たとえば、決済画面に、

**First Name**

**Last Name**

と表示されている場合があります。

この場合は、カードサービス側に登録されている名前の表記に合わせることが重要です。

日本語の漢字をそのまま入力すると、決済システムによっては正しく処理できない可能性があります。

## First NameとLast Nameの違い

海外サイトでは、名前を2つに分けて入力することがあります。

一般的には、

**First Name = 名**

**Last Name = 姓**

です。

たとえば、英字表記が、

**TARO YAMADA**

の場合、

First Name：TARO

Last Name：YAMADA

という形式になります。

ただし、サイトによって入力形式が異なることがあるため、画面の説明を確認してください。

## カード名義とアカウント名は同じ？

必ずしも同じとは限りません。

オンラインショップには、ショップ側のアカウント情報があります。

一方、カードにはカード側の名義情報があります。

そのため、

**ショッピングサイトのアカウント名**

と

**カードのCardholder Name**

は別の情報として扱われる場合があります。

決済画面でCardholder Nameを求められた場合は、カード側の情報を確認しましょう。

## カード名義が原因で決済できないことはある？

可能性はあります。

オンライン決済では、カード情報や請求先情報など複数の項目が確認される場合があります。

たとえば、

- カード番号
- 有効期限
- CVV
- カード名義
- Billing Address

などです。

入力情報に不一致があると、決済が拒否される場合があります。

ただし、カード名義が原因だと断定できないケースも多いため、決済エラーが発生した場合は他の項目も確認する必要があります。

## Cardholder Nameを適当に入力してもいい？

おすすめできません。

「何を入力すればいいか分からないから、とりあえず自分の名前を入力する」という方法は、決済が正常に処理されない原因になる可能性があります。

まずカードサービス側のカード情報を確認しましょう。

Cardholder Nameが表示されていない場合は、カードサービスのヘルプやサポート情報を確認するのが安全です。

## 海外サイトで名前の入力形式が違う場合

海外サイトでは、日本の名前の表記方法と異なるケースがあります。

たとえば、

- 姓 → 名
- 名 → 姓
- First Name / Last Name
- Full Name

など、入力方法が異なる場合があります。

この場合は、カードサービス側で使用されている正式な表記を基準にしつつ、決済画面の入力形式に合わせることが重要です。

## Billing Addressとカード名義を混同しない

海外サイトでよく一緒に表示されるのがBilling Addressです。

しかし、

**Cardholder Name**

と

**Billing Address**

は別の情報です。

Cardholder Nameはカード名義に関する情報で、Billing Addressはカード決済に関連する請求先住所です。

どちらも決済時に入力を求められる場合がありますが、それぞれ正しい情報を入力する必要があります。

## カード名義以外に確認したいカード情報

海外サイトでバーチャルカードを利用するときは、カード名義だけでなく次の情報も確認しましょう。

### カード番号

入力した番号がカード情報と一致しているか確認します。

### 有効期限

MonthとYearを正しく入力します。

### CVV

セキュリティコードを確認します。

### Cardholder Name

カードサービスに表示されている名義を確認します。

### Billing Address

必要な場合は正しい請求先情報を入力します。

### 3D Secure

追加認証が表示された場合は、認証を完了します。

## カード名義を変更できる？

カード名義を変更できるかどうかは、カードサービスの仕様によって異なります。

利用者情報を変更することでカード名義にも影響する場合もあれば、カード発行後は変更できない場合もあります。

名義変更が必要な場合は、カードサービスの公式案内を確認してください。

自己判断で決済画面だけ異なる名前を入力するのではなく、カード側の登録情報を確認することが重要です。

## 海外通販でカード名義を入力するときの注意点

海外通販では、次のような点に注意しましょう。

### 表記を統一する

カード側で英字表記が指定されている場合は、その表記に合わせます。

### 姓と名を確認する

First NameとLast Nameを間違えないようにします。

### アカウント名と混同しない

ショップのアカウント名ではなく、カードの名義を入力する項目なのか確認しましょう。

### Billing Addressと混同しない

名前と住所は別の情報です。

### 決済エラー時は他の項目も確認する

カード名義だけでなく、残高、限度額、カード番号、有効期限、CVV、Billing Addressなども確認しましょう。

## カード名義が分からない場合は？

カード情報を開いても名義が分からない場合は、次の順番で確認するとよいでしょう。

1. カード管理画面を確認する
2. Cardholder Nameなどの項目を探す
3. カードサービスのヘルプを確認する
4. FAQや利用ガイドを確認する
5. 必要に応じてサポートへ問い合わせる

分からないまま適当な情報を入力するより、正式な情報を確認してから決済するほうが安全です。

## バーチャルカードの名義は店舗側にどう表示される？

決済時にカード名義が利用先へ送信される場合があります。

ただし、具体的にどの情報が加盟店側へ表示されるかは、カードサービスや決済ネットワーク、加盟店側のシステムによって異なります。

そのため、「バーチャルカードだから必ずこの名前が表示される」と一律に考えることはできません。

## よくある質問

### バーチャルカードにもカード名義はありますか？

カードサービスによって異なる場合がありますが、オンライン決済でCardholder Nameの入力が必要になることがあります。カード管理画面などで確認できる場合があります。

### Cardholder Nameには自分の名前を入力すればいいですか？

必ずしもそうとは限りません。カードサービス側に表示されている正式なカード名義を確認して入力することをおすすめします。

### 海外サイトでは漢字で入力してもいいですか？

海外サイトでは英字入力を求められることが一般的です。カード側で指定されている名前の表記に合わせるのが基本です。

### First NameとLast Nameのどちらに姓を入力しますか？

一般的にはFirst Nameが名、Last Nameが姓です。ただし、サイトによって表示方法が異なるため、入力画面の案内を確認してください。

### カード名義が原因で決済できないことはありますか？

可能性はあります。ただし、残高、利用限度額、カード番号、有効期限、CVV、Billing Address、本人認証など、他の原因も考えられます。

### Cardholder NameとBilling Addressは同じですか？

違います。Cardholder Nameはカード名義、Billing Addressは請求先住所です。別々の情報として入力する必要があります。

## まとめ

バーチャルカードには実物のカードがないため、Cardholder Nameの入力方法に迷うことがあります。

重要なのは、**自分の名前を適当に入力するのではなく、カードサービス側に表示されている正式なカード名義を確認すること**です。

海外サイトで決済するときは、

- Cardholder Name
- Card Number
- Expiration Date
- CVV
- Billing Address
- 3D Secure

などをそれぞれ確認しましょう。

また、First NameやLast Nameなど海外特有の入力形式にも注意が必要です。

カード名義が分からない場合は、利用しているカードサービスの案内を確認してから入力することで、不要な決済エラーを避けやすくなります。
