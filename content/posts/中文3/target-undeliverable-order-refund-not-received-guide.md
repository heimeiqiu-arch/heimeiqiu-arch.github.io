Target.com 或 Target App 订单被承运商标记为 Undeliverable（无法投递）后，包裹可能被退回给 Target，买家则等待退款确认。导致无法投递的原因可能包括地址过期或不完整、邮政信箱地址格式错误、标签无法辨认、包裹尺寸或重量不符合投递要求、投递尝试失败、收件人拒收或运输途中损坏。先查看承运商追踪和 Target 订单页面，确认包裹是在退回途中、已经退回，还是订单只被取消但仍未完成退件处理。

Target 官方帮助页说明，如果承运商把无法投递的包裹退回 Target，Target 会发送邮件通知，并为订单发放全额退款（包括运费）。Target 一般建议买家在预计送达日期后4周内收到退回或退款确认。如果超过4周仍没有确认，可以进入订单页面使用 “Fix an issue”（处理问题）申请退款或替换。替换商品需看库存情况；Target 说明无法重新寄出被退回的无法投递订单，通常需要重新下单并确认新的收货地址。

## 先在承运商和 Target 页面分别核对

打开 Target 账户的 Orders（订单）或 Target App 中的 Purchases（购买记录），查看订单是否已取消、退货中、退款处理中或有新的预计日期。再打开订单详情里的追踪链接，在承运商官网核实包裹最后扫描记录、扫描日期和当前方向。承运商显示“无法投递”不一定意味着 Target 已经收到退件；包裹可能仍在承运商网络中，或者需要等待退回仓库扫描。

保存订单号、追踪号、承运商状态截图和预计送达日期。若追踪号码显示无法投递但之后没有更新，联系承运商询问包裹是否已经退回、退回至哪个地点，以及是否存在新的扫描记录。Target 官方说明，如果承运商将包裹退回 Target，Target 会发邮件告知退件并发放退款；因此要同时检查注册邮箱和垃圾邮件文件夹，不要只依赖承运商通知。

## 为什么可能出现无法投递

Target 官方列出的可能原因包括旧地址或地址错误、PO Box 格式问题、标签不清、重量或尺寸限制、投递尝试失败、收件人拒收或包裹运输损坏。若订单地址有误，先查看订单详情中是否仍可申请地址变更。Target 页面说明，某些尚未发货的商品可以在订单详情里选择 Request address change；该选项只对符合条件、尚未发货的商品显示。

如果包裹已经发出，联系承运商确认是否能安排重投、改派或拦截；能否操作取决于承运商、包裹状态和地址类型。不要假设 Target 能为已退回包裹修改地址并再次发货。Target 帮助页明确表示，作为 Undeliverable 退回的订单无法重新寄出，买家可以在确认退回或退款后用正确地址重新下单。

## 预计送达日期后4周内怎么处理

在预计送达日期之后的4周内，持续查看承运商追踪和 Target 订单记录，确认包裹是否退回。Target 官方说，买家通常会在预计送达日期后4周内收到退件或退款确认。这个时间窗口是用来判断何时继续查询的参考，不表示所有包裹一定会在第28天自动退款，也不应当代替订单详情里更具体的退款状态。

如果追踪显示包裹很久没有移动，可以先联系承运商询问。若承运商确认包裹已退回，而 Target 订单尚未显示退款，保存其答复和案件编号。若尚未退回，继续按承运商的追踪记录处理，并确认订单是否已取消。切勿在未核对原订单状态前重复下单或重复申请同一笔退款，以免同时出现仍在运输的原件和第二笔订单。

## 超过4周后使用 Fix an issue

如果距预计送达日期已超过4周仍没有收到退回确认或退款，Target 官方建议通过账户发起问题处理。登录 Target 账户，在 Target.com 的 Orders 或 Target App 的 Purchases 中找到对应商品，选择 “Fix an issue”，然后按页面提示选择退款或替换。这个选项只会出现在符合条件的订单或商品上；如果看不到，不要重复提交无关退货请求，改用 Target 的官方订单帮助入口询问资格和状态。

填写申请时说明承运商标记为 Undeliverable 的日期、是否有后续追踪、包裹是否退回，以及订单是否已取消。附上追踪号码和承运商的书面信息。Target 表示，替换订单受库存情况影响，通常按等价更换处理，不会另外收取额外费用；一旦提交替换申请，如果原商品后来送达，可能不能再把原商品直接拿去门店退货，否则会影响替换请求。提交前请阅读订单页面给出的说明。

## 退款会退回哪里

Target 官方说明，退款在多数情况下退回原始付款方式。使用 Target GiftCard 购买的订单，退款可能以新的 Target eGiftCard 形式退回到 Target 账户。不同的订单和支付方式可能有不同显示，查看订单退款详情和 Target 邮件中的退款金额及方式。若原订单使用多种付款方式或礼品卡加银行卡，核对每笔退款分别回到了哪里，不要只查看银行卡账户。

如果 Target 页面显示退款已发出但支付方式没有更新，保存 Target 退款日期、金额、付款方式和订单号码，向对应的银行卡发行机构或支付服务商查询。Target 对 undeliverable 订单页面说明会发放退款，但没有给所有银行卡规定一个统一的银行到账日期；因此不要把其他零售商的时间或论坛中某个具体银行的天数套用到自己的付款方式。

## 订单取消但仍有待处理扣款

如果 Target 订单因缺货、支付问题或取货窗口过期而取消，Target 会通过邮件说明取消原因。银行卡记录上仍可能暂时显示与原订单有关的待处理项目。先确认 Target 订单状态是否确已取消，再查看银行记录是 Pending 授权还是已经正式入账。如果只是待处理项目，向银行询问该交易是否为临时授权以及何时会释放；如果已正式入账且 Target 订单已退款，提供 Target 的退款确认向银行查询。

不要把付款记录上的一条 pending 状态和已经完成的扣款混为一谈，也不要重复支付相同订单来测试退款。若 Target 订单页面没有退款记录、但银行已出现正式收费，可联系 Target 官方支持并提供订单号、收费日期、金额和订单取消邮件。若银行表示交易属于临时授权，等待它更新并按银行给出的处理方式跟进。

## Target GiftCard 与替换订单的注意点

Target 的官方帮助说明，使用 Target GiftCard 付款的商品退款通常会退回为新的 Target eGiftCard。注意留意 Target 账户中的 GiftCards 页面和订单邮件，而不只是原实体礼品卡的余额。Target 表示被退回为无法投递的订单无法重新寄出；若选择替换，需确认库存和新订单地址。若选择退款，仍可在确认新的地址后重新购买商品。

Target 还提示，部分促销订单可能包含商品本身与促销礼品卡的分项授权。若订单中有符合条件的赠送 GiftCard，付款记录可能出现两笔授权或交易，但金额合计对应原订单。核对取消和退款时要查看完整订单与促销说明，不要将促销礼品卡相关授权误判为重复收取。与普通订单一样，退款记录和银行到账记录仍是分开的。

## 联系 Target 或银行前准备什么

准备 Target 订单号、预计送达日期、承运商和追踪号码、Undeliverable 扫描记录、Target 订单状态、退款邮件和银行交易状态。通过 Target.com 账户、Target App 或帮助中心联系官方支持。Target 可能要求你通过账户邮箱或手机验证订单所有权；只在官方订单页面或官方消息中完成验证，不要把验证码转发给卖家、承运商私信或陌生客服。

若联系银行，说明订单已取消或无法投递并询问待处理授权或退款入账状态。提供退款日期、退款金额、商户描述和 Target 可提供的参考信息。不要在公开社交平台发布完整卡号、账户余额、家庭地址或交易截图。记录客服案件编号和每次沟通日期，便于超时后继续跟进。

总结来说，Target 包裹显示 Undeliverable 时，先确认它是否已由承运商退回，再看 Target 订单和邮件是否出现退款。Target 官方建议预计送达日期后4周内收到退件或退款确认；超过4周仍没有确认，可通过订单里的 Fix an issue 申请退款或替换。退款多数退回原付款方式，礼品卡订单可能以新的电子礼品卡退回。分开核对物流、订单和付款记录，就能知道问题处于哪一步。
