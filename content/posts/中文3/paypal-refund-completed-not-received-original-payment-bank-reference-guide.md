# PayPal退款显示Completed但银行卡没到账？按状态、付款来源和参考号查询

PayPal 交易页面显示退款已完成，但银行卡或银行账户中没有看到退款，常见原因是 PayPal 已把钱送到原支付工具，发卡机构仍在处理，或者你检查的不是原来付款时使用的卡。PayPal 的退款追踪包含多个阶段：“Refund Initiated（已发起）”“Refund Processing（处理中）”“Refund Sent（已发送）”“Refund Pending（银行处理中）”和“Refund Completed（已完成）”。状态含义不同，看到其中任意一个都不代表资金必定已经在银行账单中显示。

PayPal 官方说明，退款通常返回原付款方式；部分退款也可能进入 PayPal 余额，例如原付款方式无法收款或付款者选择了余额。不同付款工具的到账时间差别很大：借记卡一般最多约5个工作日，但某些情况可能最长30天；信用卡可能需要1至2个账单周期；银行账户通常最多约5个工作日；PayPal 余额通常当天显示。具体时间会根据交易状态、发卡行和地区变化。

## 先在 PayPal 活动记录中查看 Refund Tracker

登录 PayPal 后打开 Activity（活动），用 Filters（筛选）选择 Refunds（退款），再选择日期范围并打开对应的退款交易。确认退款状态、金额、原付款方式、退款是否部分处理，以及是否显示 bank reference ID（银行参考号）。银行参考号可提供给发卡机构查询退款，不要只凭卖家邮件或交易列表中的“已退款”字样判断资金走向。

PayPal 官方追踪状态的含义如下：

- **Refund Initiated**：退款流程已经开始。
- **Refund Processing**：PayPal 正在将款项退回原卡或银行付款方式。
- **Refund Sent**：PayPal 已处理并把退款发送给银行或发卡行，但银行可能仍在记账。
- **Refund Pending**：退款正在银行或发卡机构一侧等待处理。
- **Refund Completed**：PayPal 的退款流程完成；若账单仍未显示，应联系银行并提供参考号或原交易。
- **Canceled**：PayPal 无法处理该退款，需要联系卖家了解后续。

如果退款显示 Pending，PayPal 说明卖家已发起退款，但卖家银行的资金可能还未清算；通常需最多5个工作日，超过后联系卖家核对。若显示 On hold（暂时保留），可能是卖家在原付款尚未从银行清算前发起退款，原交易清算后退款才完成。先确认原始付款是否已经入账，避免把仍在处理的付款和退款误认为两笔独立支出。

## 确认退款回到了原付款方式

打开原始 PayPal 交易，核对付款来源是 PayPal 余额、信用卡、借记卡、银行账户，还是多种付款方式组合。退款通常回到这些原来源。如果你只看当前 PayPal 余额，却用卡片付款，退款不一定会加到余额；若原付款同时使用余额和银行卡，退款可能分别回到两处。

若 PayPal 无法把款项退到原借记卡，官方说明退款可能会加到 PayPal 余额。查看 PayPal Activity、余额账户和绑定卡的末几位，确认实际退款目的地。若是已注销、换卡或补发的新卡，PayPal 可能仍向原卡信息发出退款；联系原发卡银行询问他们是否可以把款项转到新卡或账户，或退款是否会被退回。

对于 PayPal 余额付款，退款通常同日回到余额。若余额与信用卡共同付款，PayPal 余额部分通常同日退回，而信用卡部分可能需要1至2个账单周期。检查 PayPal 退款明细中的分配金额，并分别查询余额与卡账单。

## 不同付款方式需要不同等待时间

### 信用卡

PayPal 官方说明，信用卡退款可能需要1至2个账单周期才会出现在信用卡账单上。账单周期通常约28至31天。退款可能显示为独立贷记，也可能在下一账单周期抵消原交易。联系发卡行时提供 PayPal 银行参考号、退款金额、退款发出日期和原始消费信息。

### 借记卡

借记卡退款通常可在约5个工作日内完成，但受卡公司处理影响，可能最长需要30天。查看原借记卡对应的银行账户和交易记录，别只看银行卡可用余额。若PayPal活动中有参考号而银行未看到入账，请发卡行按参考号和原交易查询。

### 银行账户

银行付款来源的退款通常会自动回到原银行账户，PayPal 表示发出后通常最多约5个工作日完成。留意账户流水和待处理交易。如果 PayPal 状态是 Pending 或 On hold，先按状态说明判断问题发生在卖家银行清算、PayPal 处理还是收款银行入账。

### PayPal 余额或 eCheck

PayPal 余额退款通常当天显示。如果卖家以 eCheck（电子支票）发出退款，款项必须先由卖家银行清算；PayPal 说明该过程一般最多约5个工作日，周末和节假日不计入。退款清算后会出现在 PayPal 余额中。若页面显示 Pending 且超过预计周期，联系卖家确认 eCheck 是否已清算。

## 退款金额不等于原消费金额

若付款涉及币种转换，退款金额可能与原付款金额不同。PayPal 表示，如果退款时重新换算，退款所用汇率可能与原购买日期不同，因此最终金额会受汇率变化影响。核对时比较原交易和退款的付款币种、转换汇率、退款数额和费用，而不要只用当天的汇率估算过去交易。

如果卖家仅批准部分退款，PayPal 状态可能显示 Partially Refunded（部分退款）。对照卖家同意退款的商品、运费、税费和促销折扣。若金额不符合双方约定，先联系卖家确认退款金额和依据；PayPal 状态只表示退回资金流程，不会决定卖家应退款的商业争议。

## 超过处理时间还没收到款项怎么办

当退款达到 PayPal 的 Refund Sent 或 Refund Completed，但银行账单没有显示时，联系原发卡行或银行查询。提供 PayPal Activity 页面上的 bank reference ID、退款日期、原始交易日期、退款金额和卡片末几位。请银行查找退款是否已收到、尚未入账、与原付款合并显示，或被拒绝退回。

如果银行查不到参考号或退款记录，再通过 PayPal Message Center 或 Resolution Center 联系 PayPal，说明你已核对原付款工具和银行记录，并提供退款交易 ID 和银行查询结果。若 PayPal 显示 Canceled，官方建议联系卖家了解退款无法处理的原因；不要向陌生客服发送完整卡号、账户密码或短信验证码。

## 联系前准备资料

- PayPal 退款交易 ID 和原始付款交易 ID。
- 当前退款状态及日期。
- 退款金额、币种和退款目的地。
- 原付款方式及卡片或账户末几位。
- 如果提供，bank reference ID。
- 发卡行或银行已查询的结果。
- 卖家确认退款的邮件、订单号和沟通记录。

通过 PayPal 官方网站或应用进入活动与支持页面；联系银行时使用其官方应用或银行卡背面的电话。不要相信可以收费“加快 PayPal 退款”的个人服务，也不要共享屏幕或向他人提供验证码。

## 快速排查顺序

1. 登录 PayPal，进入 Activity → Filters → Refunds，打开目标退款。
2. 记录 Refund Initiated、Processing、Sent、Pending、Completed 或 Canceled 状态。
3. 核对原付款来源，分别检查 PayPal 余额、原卡或银行账户。
4. 按来源查看处理周期：余额当天、银行通常最多约5个工作日、借记卡约5个工作日且可能最长30天、信用卡约1至2个账单周期。
5. 若 PayPal 已发送或完成，向原付款银行提供 bank reference ID。
6. 若银行查不到，携银行查询结果联系 PayPal；若退款被取消，联系卖家核实。
7. 退款金额有差异时，查看部分退款与币种转换记录，不要只按原购买金额推断。
