# eBay卖家款项显示已发送但银行没到账？查可用余额、打款状态和参考号

eBay 卖家看到商品已售出，但银行账户没有收到钱，首先要区分订单款项是否已经“可提现”，以及 eBay 是否已经向银行发出 payout（打款）。买家付款后，款项可能先出现在 Pending（待处理）或 On hold（预留）状态；即使已成为 Available for payout（可提现），也可能要等到你设置的打款日期。只有页面显示 Funds sent（资金已发送）后，才进入银行处理阶段。

eBay 官方说明，打款进入 Funds sent 后，银行通常需要约1至3个工作日处理，具体时间取决于金融机构。部分地区的帮助页面给出不同范围，周末和银行假日也会影响结算。本文依据 eBay 美国卖家帮助页整理，具体账户规则和到账周期可能因国家、卖家身份、资金状态和银行类型不同。请以 Seller Hub 或 My eBay 的付款页面为准。

## 先看款项是否已达到可提现状态

登录 Seller Hub 或 My eBay 的 Payments（付款）页面，找到具体订单或打款记录。订单销售款可能显示 Pending、On hold 或 Available。Pending 通常表示付款已开始处理但还未成为可提现余额；On hold 表示 eBay 暂时保留款项，等待订单完成、物流状态更新或账户资料核验。此时银行没收到并不一定是打款延迟，因为款项可能还未进入银行转账阶段。

eBay 的交易预留与账户打款冻结不是同一种状态。某一笔订单的交易款被预留，通常是为确认交易顺利完成或等待买家收到商品；整个账户的 payout blocked 或 payout hold 则可能需要解决身份、合规、付款方式、税务或账户表现问题。页面会显示当前状态及可能需要完成的事项。不要只看账户总余额，而忽略每笔订单和可提现金额的明细。

如果是新卖家，部分订单款可能要等待物流确认后才释放。eBay 当前帮助页根据运输方式和新卖家情况列出不同的典型释放时间，例如使用 eBay 运单且有送达确认、使用第三方运单、或没有追踪信息时，等待时间可能不同。具体日期应查看订单的资金释放详情，避免把案例中其他卖家的天数当成自己的固定承诺。及时上传有效追踪并在处理时间内发货，有助于 eBay 确认交付状态。

## 检查打款计划和账户是否需要你手动提款

即使款项已可提现，也可能未到你设置的 payout schedule（打款计划）。eBay 支持每日、每周、每两周或每月等计划，账户所用设置会决定什么时候发起转账。若你的账户使用 eBay balance 并且采用按需打款，款项可能需要你在 Payments 页面主动选择 Withdraw（提款），才会发往银行。进入账户查看可提现金额、下一次打款日期和是否存在待操作按钮。

如果预计打款日是银行假日，eBay 可能在下一个可用打款日发送。周末提交的打款也可能在银行的下一个工作日完成结算。查看交易的发起日期和所在地银行的工作日历，不要按自然日简单计算。更改打款计划通常影响后续资金发送安排，不会让还处于 Pending、On hold 或账户审核状态的款项立即可提现。

## 看懂 eBay 的打款状态

打开 Seller Hub 的 Payout details（打款详情）查看状态、金额和收款账户。状态大致含义如下：

- **Created**：系统创建了打款编号，流程已开始。
- **In progress**：eBay 已发起打款，款项正在发送给银行。
- **Funds sent**：eBay 已成功发送，银行还需要完成处理。
- **Returned**：打款曾被发起，但银行或 eBay 处理过程中出现问题。
- **Blocked**：打款方式可能无效，或账户存在限制。
- **Canceled/Cancelled**：打款失败，款项已重新加入可用余额。

不同地区页面的状态名称可能略有差异。若页面是 Funds sent，查看它的发起日期、打款 ID 和银行 reference ID（银行参考号）；若为 Returned 或 Blocked，则先解决账户信息、验证或银行拒收问题，而不是等待普通到账周期。若状态是 Canceled，确认对应资金已经回到可用余额，再查看下一次提款安排。

## 银行信息是否正确，打款是否去了旧账户

在 Payout details 中核对收款银行账户与当前使用账户是否一致。确认银行账户姓名、账号末几位和账户类型正确。eBay 美国帮助页提示，接收普通打款需要合资格的 checking account；其他地区可能使用不同的银行账户要求。不要假设 PayPal 或储蓄账户可以作为每个地区的默认收款方式，应以自己账户的付款设置页面为准。

如果你在 payout 已经发起之后才更新银行资料，本笔打款仍可能发往发起时的旧账户；更新新账号通常只影响之后的打款。若旧账户仍然有效，尽快联系原银行查询款项；若账户已关闭，银行可能拒收并把资金退回 eBay，或联系你处理。修改资料不会自动重定向在途款项。

如果打款状态显示 Returned，检查 eBay 是否要求重新验证身份、更新银行资料或补充文件。eBay 可能通过 Seller Hub 提示、Messages（站内消息）或电子邮件联系你。用自己保存的书签或手动输入 eBay 官方网站进入账户，确认消息是否真实；不要点击陌生人发来的链接，也不要把验证码提供给自称客服的人。

## 已显示 Funds sent 但过了预计时间

eBay 官方页面建议，已发送后的打款可能需要银行约1至3个工作日处理。先检查银行流水的待入账、已入账和被拒收交易，并核对币种。若买家付款货币与打款货币不同，eBay 可能进行币种转换；订单详情会记录适用的兑换信息，最终到账金额不一定等于买家支付的原始币种金额。

超过页面时间后，使用 Payout details 中的 bank reference ID 联系收款银行查询。提供打款发起日期、准确金额、付款方 eBay、银行账户末几位和参考号。银行可以查找已收到但尚未显示、待处理或被退回的转账。若银行确认没有收到，保留银行查询结果并通过 eBay 官方支持提交 payout ID 与参考号，要求核查付款状态。

## 联系前准备的信息

准备订单编号、payout ID、付款页面状态、打款日期和金额、币种、收款银行账户末几位、银行参考号、银行查询结果，以及账户是否收到身份或税务验证通知。若款项还在预留，记录订单物流状态、追踪号码和预计释放日期。只通过 eBay 账户内的帮助渠道、银行官网或银行卡背面电话联系。

不要在公开聊天、社交媒体或论坛发布完整银行账号、税务识别号、密码或一次性验证码。客服核查通常需要能够定位的订单与打款信息，但不需要你交出登录密码。若有人声称支付解冻费即可立即释放 eBay 款项，停止沟通并从官方账户重新进入支持页面。

## 快速排查顺序

1. 在 Payments 页面查看销售款是 Pending、On hold 还是 Available。
2. 查看账户或订单的预计可用日期及是否有预留或验证提示。
3. 检查 payout schedule，确认打款是否需要手动提款。
4. 打开打款详情，确认状态是 Funds sent、Returned、Blocked 还是 Canceled。
5. 核对本次打款发往的银行账户和账户持有人资料。
6. 若显示 Funds sent，按工作日等待银行处理，并用 bank reference ID 查询。
7. 若 Returned 或 Blocked，按 eBay 通知处理账户验证、银行资料或税务信息。
8. 银行确认未收到后，向 eBay 官方支持提交 payout ID、参考号和银行查询结果。
