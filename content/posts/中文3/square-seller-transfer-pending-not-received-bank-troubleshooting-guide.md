Square 商户完成收款后，资金会按账户设置的转账计划进入已关联的银行账户或借记卡。如果你看到 Square 余额已变动，但银行账户没有入账，先不要立刻重复发起转账。先在 Square Dashboard 查清这笔款是 Standard next-business-day（下一个工作日）、Same-day（当日）、Instant（即时）还是 Manual（手动）转账，再根据交易状态、目标账户末几位和预计到达时间判断是正常处理、验证未完成，还是确实需要追踪的转账。

下面主要依据 Square 美国商户帮助中心。其他国家、地区、账户类型和转账方式的费用及时间可能不同，尤其要注意金额限额、时区和银行假日。请优先以你的 Dashboard 中显示的转账状态、预计到达日期和实际选择的银行账户为准。

## 在 Square Dashboard 找到具体转账

登录 Square Dashboard，进入 Banking > Transfers（银行 > 转账），选择对应门店并用日期范围筛选。点开转账记录，查看状态、转账方式、预计到账时间、目标银行账户末三位、所包含的银行卡付款以及相关追踪信息。如果使用 Square App，进入 Banking > Transfers，再选择 View all activity（查看全部活动），从 History（历史）中点开转账查看详情。

Square 官方指出，仪表盘可以显示 Pending、Completed 或 Failed 等状态，以及转入的银行账户末三位和预计到达时间。先把这些信息与自己银行账户核对，不要只依靠银行推送或 Square 余额总数判断。若你经营多个地点，确认查看的是收取这笔款项的正确 Location；不同地点可能有不同转账记录和银行设置。

记录交易金额、日期、状态、转账类型、目标账户末三位和预计到账日期。如果记录中有trace details（追踪信息），在与银行沟通时一起提供。不要把完整银行账号、登录密码、验证码或客户银行卡信息发到公开论坛或社交媒体。

## 先确认转账速度和工作日安排

Square 美国帮助页面提供多种转账方式：标准下一个工作日转账、当日转账、即时转账和手动转账。标准转账按账户计划自动发往已关联账户；即时转账通常收取费用；当日转账则按账户设置的营业日和关店时间处理；手动转账由商户决定发起时间。不同方式的时间、资格和费用不同，不能仅凭“Square 付款已完成”推断银行已收到款项。

Square 的标准计划按太平洋时间下午5点/东部时间晚上8点的截止时间处理。截止前收取的款项通常下一个工作日到达银行；晚于截止时间收取的款项通常到第二个工作日。周五的收款可能在周一早上入账，具体仍受银行处理速度影响。标准下一个工作日转账在星期六不会发送；周末和银行假日可能让可见到账时间后移。

若你预期周末收到款项，检查 Dashboard 里是否启用了周末余额或是否另选即时转账。官方说明，默认情况下周五资金可能留在 Square 余额中，供商户在周末选择即时转出；若不即时转账，款项一般仍按计划在周一到账，遇银行假日可能是周二。核对账户实际设定，别把商户可选的即时方式误当成已自动执行。

## Instant 或 Same-day 转账为什么无法使用

即时和当日转账并非所有余额都能使用。Square 美国支持页面列出即时转账的最低余额为扣除 Square 费用后25美元，单笔上限通常为10,000美元；当日转账最低金额为扣除费用后1美元，金额也受到最高限额约束。超过限额、低于门槛或不符合资格的资金可能按通常计划转入银行，而不是通过即时或当日方式处理。

新 Square 商户初始即时转账额度可能是每天一次、最多2,000美元。随着账户持续正常使用，Square 可能提高每日转账额度，但不应把其他商户的额度当成你账户的保证。单笔金额或账户限制以 Dashboard 实际显示为准。若即时选项没有出现，先确认可转余额、费用扣除后的金额、当日已使用次数和收款账户是否符合资格，不要反复点击提交。

Square 的转账设置还可能因账户类型而不同。官方说明，使用 Square API 的卖家在积累足够账户历史前，可能无法使用即时转账。若你的账户通过 API 集成、某个门店或特定地区运行，先在 Square Dashboard 查看可用功能与待办通知，不要假设普通 POS 商户的菜单路径和资格完全适用。

## 银行账户还在验证，资金可能仍留在 Square

在第一次从 Square 收款之前，需要添加并验证银行账户或符合条件的借记卡。Square 官方说明，人工银行验证最多可能需要4个工作日，不含周末和节假日；验证期间你仍可收款，但资金会保留在 Square 余额，银行完成验证后，款项会按设置的转账计划自动发出。

打开 Square Dashboard 的 Account & Settings > Banking > Bank accounts，查看银行验证状态和邮箱通知。若采用人工验证，按照 Square 的提示核对银行账号及小额验证金额；官方说明账户中应至少有1美元，以完成可能涉及的小额存入和扣回。不要在验证尚未完成时重复更换多个银行账户，除非 Square 指引或支持明确要求。

核对银行账号、routing number、户名和账户类型是否输入准确。Square 表示需要一个可以接收并处理入账、在需要时也能处理退款或争议相关资金的交易账户；预付卡不受支持。信用合作社可能用于 ACH 的电子账号与纸质支票上的账号不同，应向银行确认适用于电子转账的账号信息。

## 账户审查或信息请求会暂停转账

若 Square 系统检测到需要确认的异常情况，可能暂时暂停包括即时转账在内的转账功能。Square 美国帮助页面说，常规账户审查通常在一个工作日内完成；如果需要额外资料，Square 会通过邮箱联系商户。打开 Dashboard 的 Settings > Account & settings > Information requests，确认是否有待提交的业务或身份信息。

在资料请求完成之前，Square 可能不允许商户把资金转出平台。按要求提供真实、完整且与账户一致的信息；如不理解具体文件要求，通过 Square 官方支持入口询问，不要向陌生人发送公司银行密码、卡片验证码或完整客户支付信息。若你选择暂时不提交所需资料，转账可能继续暂停；应先理解平台提示，而不是反复更改结算方式尝试绕过审核。

如果 Square 的转账记录显示 Pending，且预计时间尚未超过 Dashboard 中给出的日期，先按该日期跟进。若超过预计窗口，并且收款银行查不到这笔入账，再联系 Square 并提供转账记录和追踪信息。不要在没有确认原转账状态前，重复申请相同金额的提现，否则可能产生重复转账或更多核账工作。

## 绑定的银行账户已经关闭

如果款项发往已关闭的银行账户，Square 可能在转账发出后才收到银行通知。之后可能出现不同结果：银行拒收并把资金退回 Square、银行保留账户并接受资金，或银行把款项处理为寄送支票。先向原银行核实账户关闭后是否仍能收到 ACH 入账，是否有支票或资金退回记录。

Square 官方说明，如果已关闭账户拒收转账，资金退回 Square 可能需要最多7个工作日；如果资金已退回且你已绑定并验证新账户，Square 会自动按规则重新发送。若新银行账户还没通过验证，资金可能继续留在 Square 余额中，直到验证完成。检查 Square 邮件，留意是否收到转账退回和重新发出的状态更新。

联系旧银行时，向 ACH 部门或可以查询电子入账的人员说明转账日期、金额、Square 提供的追踪信息和收款账号末三位。先确认旧账户有没有收到、拒收或以支票形式处理资金；若银行无法查到，再把银行核查结果提供给 Square 支持。避免在新账户尚未验证时删除全部旧记录，以免查找原交易困难。

## 预期的销售款没有进入转账记录

若某笔销售收入根本没有出现在转账详情里，先检查 Square 支付记录是否完成，而不是 Pending、Failed 或仍等待结算。查看对应付款是否被记为银行卡交易；使用现金、支票或其他自定义 Tender（付款方式）记录的销售，不是通过 Square 处理的银行卡付款，因此不会以同样方式进入 Square 银行转账。

离线模式的付款会按照正常转账计划，在数据上传后才进入处理。若交易使用了纸质收据签名或小费流程，可能需要先完成结算，之后才转入银行。把 Square 付款列表、关店结算、离线记录和转账详情放在一起核对，才能分辨是支付尚未完成、转账还在计划中，还是款项被记到了其他支付方式。

## 联系银行或 Square 时准备什么

在联系银行前，先从 Dashboard 导出或记录这笔转账的日期、金额、转账方式、状态、目标账户末三位和追踪信息。请银行确认是否收到了该笔 ACH 或即时转账，是否拒收、是否正在待处理，以及该账户是否处于关闭或限制状态。银行查不到账时，记下客服姓名、联系日期、案件编号及查询结论。

联系 Square 时提供同样的信息，以及账户所属门店、银行验证状态、付款记录是否已完成、账户是否有待提交的信息请求、你选择的转账计划和银行反馈。Square 的缺失转账指南建议，如果款项超出预期时间且银行找不到这笔资金，再联系 Square 寻求帮助。不要只说“我没收到”，需要指出具体转账和实际账户末三位，客服才能定位正确记录。

Square 商户转账未到账时，先在 Dashboard 里对齐转账方式、状态、预计日期和目标账户，再检查截止时间、周末安排、银行验证、金额限制及账户信息请求。标准转账、Same-day 和 Instant 使用不同的时间与资格；已关闭的银行账户也可能让资金退回并等待重新验证。准备 Square 的转账追踪详情和银行查询结果，通常更容易判断资金当前停在哪里。
