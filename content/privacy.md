## 适用范围

本说明适用于托管在 `heimeiqiu-arch.github.io` 的静态信息网站。以下内容根据本站当前公开代码核对，最后核对日期：2026-11-18。本站由个人运营；联系方式见本页末尾。

## 本站页面的处理情况

- 当前页面没有账号注册、支付/充值、联系留言或文件上传表单；本站本身不收集这些表单数据，也不提供支付入口。
- 当前代码未发现 Google Analytics、Google Tag Manager、Google Ads 衡量代码、广告像素或其他访客行为分析脚本。Google Ads 衡量代码处于暂停状态。
- 页面脚本使用浏览器 `localStorage` 保存主题偏好（`pref-theme`）和导航菜单滚动位置（`menu-scroll-position`），用于记住显示设置。这些值保存在当前浏览器中；本站脚本不会把它们发送到本站服务器。清除浏览器对此站点的本地存储即可移除这些偏好。
- 站内搜索读取本站同一域名提供的 `index.json` 搜索索引。代码示例的复制按钮只会在访客主动点击后调用浏览器剪贴板功能。
- 本站前端代码没有自行读写浏览器 Cookie 的逻辑。此项仅说明本站代码；托管服务可能按其自身规则处理访问请求。

## GitHub Pages 托管

本站由 GitHub Pages 托管。GitHub 说明，访问 GitHub Pages 网站时会为安全目的记录并存储访客 IP 地址。该记录由托管服务提供方按其规则处理，本站代码不读取该记录。详情请查看 [GitHub Pages 文档](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection) 和 [GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)。
